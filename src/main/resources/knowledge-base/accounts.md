# Checking and Savings Accounts

## Checking Accounts

### Features
- Unlimited transactions
- Debit card included
- Online and mobile banking
- Bill pay services
- Mobile check deposit

### Types
- **Standard Checking** - No monthly fee with minimum balance of $500
- **Premium Checking** - No minimum balance, includes overdraft protection ($5/month fee)
- **Student Checking** - For students under 25, no fees with valid student ID

### Opening an Account
1. Provide valid government-issued photo ID
2. Provide Social Security Number or Tax ID
3. Initial deposit of $25 for standard checking
4. Complete application online or at any branch

## Savings Accounts

### Features
- Competitive interest rates
- Unlimited deposits
- Automatic savings tools
- Linked to checking for easy transfers

### Types
- **Standard Savings** - 0.5% APY, no minimum balance
- **High-Yield Savings** - 2.5% APY, $1,000 minimum balance
- **Goal Savings** - Custom savings goals with automatic contributions

### Opening an Account
1. Provide valid government-issued photo ID
2. Provide Social Security Number or Tax ID
3. Initial deposit of $25

## Account Maintenance

### Monthly Fees
- Standard Checking: Waived with $500 minimum balance
- Premium Checking: $5/month (waived with $5,000 minimum balance)
- Standard Savings: No monthly fee
- High-Yield Savings: No monthly fee

### Closing an Account
1. Transfer all funds to another account
2. Submit account closure request online or at a branch
3. Allow 5-7 business days for processing
4. Receive written confirmation of closure
